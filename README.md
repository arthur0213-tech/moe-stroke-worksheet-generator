# 臺灣教育部標準筆順 - 姓名與生字練習簿生成系統

專為國小教師與家長設計的純前端、高解析度向量「姓名與生字筆順習字帖生成器」。
所有筆順次序與楷體字形嚴格依據**中華民國教育部《常用國字標準字體筆順學習網》**標準，完全符合教育部規範。

---

## 🌟 核心特色

1. **100% 臺灣教育部筆順標準**
   - 整合教育部 6,000+ 常用國字標準字體向量筆畫資料庫。
   - 保證為標準正體楷書筆順（非簡體或日韓漢字筆順）。

2. **筆畫逐步分解練習**
   - **首格**：全字標準黑體示範。
   - **接續格**：第 1 畫 ➔ 第 1+2 畫 ➔ 第 1+2+3 畫……逐步累積至全字完成，帶著學生一筆一劃學習運筆。
   - **描紅行**：整行全字淺灰描摹格，供學生以鉛筆覆寫練習。
   - **空白行**：全行空白習寫格，讓學生自我挑戰獨立書寫。

3. **🌟 專屬護貝大字白板卡模式 (專供白板筆反覆擦寫)**
   - **大字姓名**：全版面放大呈現學生的姓名大字，適合低年級學生手部肌肉運筆。
   - **雙格擦寫**：包含「大字描紅格」與「大字自主擦寫格」，印出護貝後可使用白板筆無限次練習！
   - **旁邊筆畫順序提示**：在大字旁清楚附上完整 1..N 畫的微型筆順逐步累積分解條。
   - **起筆序號標記與筆劃導引虛線/箭頭**：直接在大字上標示每筆開頭位置與動態運筆方向。

4. **擴充支援 twpen.com 筆順字典**
   - 當教育部資料庫未收錄特殊字、罕用字或人名字時，自動擴充比對 twpen.com 字庫，透過中軸骨架與向量輪廓演算法動態生成筆順與導引箭頭。

5. **強大且貼心的教師功能**
   - **單生模式**：輸入姓名即可即時產生。
   - **全班批次產生模式**：直接貼上全班名單，系統自動一鍵生成全班所有人的練習單，每人獨立一張 A4，整批列印超級省時！
   - **自訂生字與語詞模式**：可自由輸入課文生字或成語詞彙。

6. **豐富的排版自訂選項**
   - **格線樣式**：田字格（標準十字虛線）、米字格（米字虛線）、十字格、方格。
   - **格線色彩**：經典教學紅、質感灰、典雅黑、護眼綠。
   - **每行格數**：12 格（相片標準）、11 格、10 格（大字練習）。
   - **紙張方向**：A4 直向、A4 橫向。
   - **頁首資訊欄**：自訂學校抬頭、年級班級、座號、姓名、評分欄位。

7. **離線可用與極致列印品質**
   - 查詢過的國字自動快取在瀏覽器中，無網路環境亦可重複產出。
   - 向量 SVG 格式輸出，直接按「列印 / 另存為 PDF」，保證 300+ DPI 印刷級銳利度。

---

## 🚀 如何使用

1. **直接線上使用**：支援 GitHub Pages 直接開啟。
2. **快速本機啟動**：雙擊資料夾中的 `啟動練習簿網站.bat`，或直接使用 Chrome / Edge 瀏覽器開啟 `index.html`。
3. **列印或儲存**：
   - 點擊右上角「**🖨️ 列印 / 另存為 PDF**」（或鍵盤按下 `Ctrl + P`）。
   - **重要提示**：在瀏覽器列印設定的「更多設定」中，請勾選「**背景圖形** (Background graphics)」，格線與淡描紅色彩才會完美印出！

## 📁 檔案結構說明

- `index.html`：系統主網頁應用程式
- `啟動練習簿網站.bat`：Windows 一鍵桌面快速啟動捷徑
- `css/style.css`：介面風格與 A4 向量列印樣式表 (`@media print`)
- `js/moe_parser.js`：教育部標準筆順與 twpen.com 解析與中軸骨架骨架導引演算法
- `js/worksheet_generator.js`：向量田字格/米字格、逐步分解格、護貝白板卡與 A4 排版核心
- `js/app.js`：使用者介面互動、批次名單處理、縮放與筆順動畫控制器
